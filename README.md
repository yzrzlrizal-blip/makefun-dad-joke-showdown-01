One line, 200 characters, one dad joke told the way a father would tell it across the dinner table. The program writes a single original dad joke to `/output/entry.txt`: a front door that loses it laughing — "unhinged" doing double duty as a door off its hinges and a person cracking up. Clean pun, fresh angle, setup short, punchline at the end, and it reads naturally aloud.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR` or `OUTPUT_DIR` for local testing).
